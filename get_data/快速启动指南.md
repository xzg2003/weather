# 气象数据采集系统 - 快速启动指南

## 第一步：启动 InfluxDB 数据库

1. 进入 `influxdb` 目录
2. 双击运行 `start_influxdb.bat`
3. 等待启动完成（看到 "Listening on HTTP" 信息）

## 第二步：初始化 InfluxDB

1. 打开浏览器，访问 http://localhost:8086
2. 首次访问会看到初始化页面，按以下步骤配置：

   **用户设置：**
   - Username: `admin`（或自定义）
   - Password: 设置一个强密码（至少8位）
   - Confirm Password: 再次输入密码

   **组织和存储桶设置：**
   - Organization Name: `weather_station`（必须使用这个名称）
   - Bucket Name: `weather`（必须使用这个名称）

3. 点击 "Continue" 完成配置
4. **重要：** 在下一个页面会显示 API Token，**务必复制保存这个 Token**

## 第三步：配置气象数据采集程序

1. 打开 `config.env` 文件
2. 将刚才复制的 Token 粘贴到 `INFLUXDB_TOKEN=` 后面
3. 检查串口配置（COM3），如果不对请修改
4. 保存文件

示例配置：
```
INFLUXDB_URL=http://localhost:8086
INFLUXDB_TOKEN=你复制的Token（很长的一串字符）
INFLUXDB_ORG=weather_station
INFLUXDB_BUCKET=weather
SERIAL_PORT=COM3
```

## 第四步：安装 Python 依赖

打开命令行（CMD 或 PowerShell），执行：

```bash
# 如果使用 conda
conda create -n weather_station python=3.10 -y
conda activate weather_station
pip install -r requirements.txt

# 或者直接使用 pip
pip install -r requirements.txt
```

## 第五步：运行气象数据采集程序

```bash
python weather_collector.py
```

程序会每分钟自动采集一次数据并上传到 InfluxDB。

## 查看数据

1. 访问 http://localhost:8086
2. 登录（使用第二步设置的用户名和密码）
3. 点击左侧菜单的 "Data Explorer"（数据浏览器）
4. 在查询构建器中：
   - FROM: 选择 `weather` bucket
   - Filter: 选择 `_measurement = weather`
   - Filter: 选择 `_field = temperature`（或 humidity、pressure）
5. 点击 "Submit" 查看数据图表

## 停止程序

- 停止数据采集：在运行 `weather_collector.py` 的窗口按 `Ctrl+C`
- 停止 InfluxDB：在运行 `start_influxdb.bat` 的窗口按 `Ctrl+C`

## 常见问题

### 1. 串口连接失败
- 检查设备是否已连接
- 确认 COM 端口号（在设备管理器中查看）
- 修改 `config.env` 中的 `SERIAL_PORT`

### 2. InfluxDB 连接失败
- 确认 InfluxDB 正在运行
- 检查 Token 是否正确复制
- 确认组织名和 Bucket 名是否正确

### 3. 找不到 Token
如果忘记保存 Token，可以在 InfluxDB Web 界面重新生成：
1. 登录 http://localhost:8086
2. 点击左侧 "API Tokens"
3. 点击 "Generate API Token" -> "All Access API Token"
4. 复制新生成的 Token

## 数据备份

定期备份 `influxdb/data` 目录即可保存所有历史数据。
